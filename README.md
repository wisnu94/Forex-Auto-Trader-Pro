# Forex Auto Trader Pro

Professional algorithmic forex trading system.

## Project Status

Current Version: V0.1 Foundation

Development Status: In Development

Live Trading: DISABLED

## Objectives

Forex Auto Trader Pro is designed to become a systematic,
risk-controlled and testable automated forex trading system.

The system will eventually support:

- Multi-timeframe market analysis
- Trend detection
- Market structure
- Liquidity analysis
- Order Block analysis
- Entry confirmation
- BUY / SELL signals
- Automatic position sizing
- Stop Loss
- Take Profit
- Break Even
- Trailing Stop
- Risk management
- Backtesting
- Paper trading
- Demo trading
- Performance analytics
- Automated execution

## Development Principles

1. Risk management comes before profitability.
2. Every strategy must be backtested.
3. No live trading during development.
4. No hard-coded credentials.
5. Every important component must be testable.
6. Avoid overfitting.
7. Preserve reproducibility.
8. Prefer fewer high-quality trades over excessive signals.

## Safety

Live trading is disabled by default.

Real-money trading must never be enabled automatically.

Before live deployment, the system must pass:

- Unit tests
- Strategy tests
- Backtesting
- Walk-forward testing
- Paper trading
- Demo trading
- Risk-control verification
